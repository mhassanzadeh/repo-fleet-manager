# Patch Notes - v0.3.0 Local-only Repository Fleet

## Added

- Added `local` command group:
  - `rfm local remotes`
  - `rfm local init`
  - `rfm local clone`
  - `rfm local bootstrap`
- Added local provider support with `type: "local"` and `file://{root}/{namespace}/{repo}.git` URL templates.
- Added local bare remote creation under `.repo-fleet/remotes`.
- Added local workspace bootstrap that creates root repo, real Git submodules, `.gitmodules`, and local origins without GitHub/GitLab.
- Added mirror/fork source support through repository fields:
  - `mirror_source`
  - `upstream_url`
  - `source_url`
  - `fork_from`
  - `clone_url`
  - `local_source`
- Added local provider audit support through `rfm repos audit --provider local`.
- Added local bare repository creation through `rfm repos create --provider local`.
- Added Bash/Fish completion entries for the new `local` commands.
- Added Makefile helpers:
  - `make local-remotes`
  - `make local-remotes-apply`
  - `make local-bootstrap`
  - `make local-bootstrap-apply`
- Added `docs/08-local-only-workflows.md`.
- Added local workflow test coverage.

## Changed

- Version bumped from `0.2.0` to `0.3.0`.
- Config loader now supports provider `type`, local config, and `{root}` placeholder in provider URL templates.
- `submodules sync` and `repos audit` can use arbitrary provider names from config, not only GitHub/GitLab.
- Root `.gitignore` generated by local bootstrap now excludes local runtime paths:
  - `.repo-fleet/build/`
  - `.repo-fleet/tmp/`
  - `.repo-fleet/remotes/`
